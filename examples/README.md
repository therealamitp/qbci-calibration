# Verified software artifacts

`verification.json` records executed local tests and synthetic examples. `circuit_checks.json` contains numerical normalization, invariance, trainability and classical-twin checks. Neither file contains real EEG performance evidence.

Generate full synthetic predictions, scores and resource logs with the commands in the main README. They are written under ignored `outputs/` directories so demonstration scores are not confused with a released empirical study. The default synthetic fixture is intentionally simple and is not a benchmark for ranking models.
