# Contributing

Run `python -m unittest discover -s tests -v` and include a reproducible command for behavioral changes. Preserve the separation between development data, calibration prefixes, and evaluation suffixes. Add regression tests for any change to data access, trial ordering, covariance fitting, kernel estimation, or the label ledger.

Do not commit EEG recordings, downloaded papers, credentials, proprietary model weights, or identifiable participant information. Describe data licenses and download commands instead. Keep synthetic verification separate from empirical EEG findings.

Report numerical tolerances, software versions, seeds, failed runs, and computational cost. A negative result or a classical explanation for an apparent quantum gain is a useful contribution. Architecture changes after confirmation begins require a new exploratory analysis designation and a new held-out confirmation set.
